# gti# ADVENTURE ESCAPE WEBSITE

## 1. Project Description
Adventure Escape is a simple website that provides information about outdoor adventure activities. Visitors can learn about the company, view activities, check prices and contact the business.

## 2. Project Pages
The website contains five HTML pages:

- home.html – The home page.
- about.html – Information about Adventure Escape.
- activities.html – Shows the available activities.
- fees.html – Displays prices and includes a fee calculator.
- contact.html – Contains contact information and a contact form.

## 3. Technologies Used
- HTML – Used to create the website structure.
- CSS – Used to style the website.
- JavaScript – Used to make the website interactive.

## 4. Project Files
- home.html
- about.html
- activities.html
- fees.html
- contact.html
- style.css
- script.js
- README.txt

## 5. How to Run the Website
1. Open Visual Studio Code.
2. Open the Adventure Escape project folder.
3. Make sure all the project files are in the same folder.
4. Open home.html.
5. Right-click and select "Open with Live Server".
6. The website will open in your browser.

## 6. Main Features
- Navigation menu.
- Information about adventure activities.
- Activity prices.
- Fee calculator.
- Contact form.
- Responsive design for different screen sizes.

## 7. Conclusion
The Adventure Escape website was created to help visitors learn about outdoor activities and make enquiries. HTML, CSS and JavaScript were used to develop the website.
